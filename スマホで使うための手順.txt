Reel & Places をスマホで使うための手順
作成日：2026年9月10日

============================================================
0. この手順で行うこと
============================================================

このアプリは、GitHub Pages（ギットハブ・ページズ）を使って無料で公開できます。
公開後のURLをiPhoneまたはAndroidで開き、ホーム画面へ追加すると、
アプリのようにアイコンから起動できます。

このリポジトリの場合、公開後のURLは通常、次のようになります。

https://bookanae.github.io/recording/

重要：

・映画、食事、旅行などの記録はGitHubには保存されません。
・記録や写真は、使用しているスマホのブラウザ内（IndexedDB）に保存されます。
・アプリのソースコードはGitHub Pagesで一般公開されます。
・ブラウザのデータを消した場合に備えて、定期的にバックアップしてください。
・最初のページ表示と地図表示にはインターネット接続が必要です。


============================================================
1. 最初に確認するもの
============================================================

公開に必要なファイルは、recordingフォルダの直下にあります。

・index.html   …… アプリの画面
・styles.css   …… デザイン
・app.js       …… 保存、検索、地図などの機能
・README.md    …… アプリの説明

現在のローカルリポジトリは、次のGitHubリポジトリへ接続されています。

https://github.com/bookanae/recording

公開作業はパソコンで行うのがおすすめです。
GitHubのユーザー名とパスワード、または認証済みのGitHub環境を用意してください。


============================================================
2. ファイルをGitHubへアップロードする
============================================================

【方法A：PowerShellを使う方法（おすすめ）】

1）WindowsでPowerShellを開きます。

2）次の行をコピーして貼り付け、Enterキーを押します。

cd "C:\Users\tanak\OneDrive - 株式会社　ウェルリサーチ　\ドキュメント\hobby\recording"

3）次のコマンドで、GitHubへ送るファイルを登録します。

git add index.html styles.css app.js README.md "スマホで使うための手順.txt"

4）次のコマンドで、変更内容に名前を付けて保存します。

git commit -m "映画・場所ログアプリを公開"

5）次のコマンドで、GitHubへ送信します。

git push origin main

6）ブラウザで次のページを開き、上記のファイルが表示されていることを確認します。

https://github.com/bookanae/recording

補足：

・gitコマンドが見つからない場合は、下の「方法B」を使ってください。
・GitHubへのサインイン画面が出た場合は、画面の案内に従ってサインインします。
・パスワードや秘密の情報を、このリポジトリへ追加しないでください。


【方法B：GitHubのWeb画面からアップロードする方法】

1）パソコンのブラウザで次のリポジトリを開きます。

https://github.com/bookanae/recording

2）GitHubへサインインします。

3）リポジトリ上部の「Add file（ファイルを追加）」を押します。

4）「Upload files（ファイルをアップロード）」を選びます。

5）recordingフォルダから、次のファイルを画面へドラッグします。

・index.html
・styles.css
・app.js
・README.md
・スマホで使うための手順.txt

6）画面下部の変更内容欄へ、例えば次のように入力します。

映画・場所ログアプリを公開

7）mainブランチへ直接保存する設定を選び、「Commit changes」を押します。


============================================================
3. GitHub Pagesを有効にする
============================================================

1）次のリポジトリを開きます。

https://github.com/bookanae/recording

2）リポジトリ上部の「Settings」を押します。

「Settings」が見つからない場合は、上部の「…」内に入っていることがあります。

3）左側のメニューから「Pages」を選びます。

4）「Build and deployment」という項目を探します。

5）「Source」で「Deploy from a branch」を選びます。

6）「Branch」で次のように選択します。

ブランチ：main
フォルダ：/ (root)

7）「Save」を押します。

8）公開処理が始まります。通常は数分待ちます。

9）同じPages画面を再読み込みします。

10）「Your site is live at ...」または「Visit site」が表示されたら公開完了です。

公開URL：

https://bookanae.github.io/recording/

注意：

GitHub Freeを使用している場合、通常はリポジトリをPublic（公開）にする必要があります。
このアプリの記録や写真はブラウザ内に保存されるため、通常はGitHubへアップロードされません。
ただし、リポジトリに手作業で置いたファイルは誰でも閲覧できる可能性があります。


============================================================
4. iPhoneでホーム画面に追加する
============================================================

1）iPhoneでSafariを開きます。

ChromeやLINEなどのアプリ内ブラウザではなく、Safariを使うのがおすすめです。

2）Safariのアドレス欄へ次のURLを入力して開きます。

https://bookanae.github.io/recording/

3）地図、一覧、履歴、追加の各画面が表示されることを確認します。

4）Safariの「共有」ボタンを押します。

Safariの表示設定によっては、「その他」ボタンを押してから「共有」を選びます。

5）メニューを下へスクロールし、「ホーム画面に追加」を押します。

表示されない場合は、メニュー最下部の「アクションを編集」から
「ホーム画面に追加」を有効にします。

6）「Webアプリとして開く」というスイッチが表示された場合は、オンにします。

7）名前を確認します。「Reel & Places」など、好きな名前へ変更しても構いません。

8）右上の「追加」を押します。

9）ホーム画面へ追加されたアイコンをタップして、アプリを起動します。

以後は、このアイコンから開くとスマホアプリのように使用できます。


============================================================
5. Androidでホーム画面に追加する
============================================================

1）AndroidでGoogle Chromeを開きます。

2）次のURLを開きます。

https://bookanae.github.io/recording/

3）アドレスバー右側の「︙」メニューを押します。

4）「ホーム画面に追加」を選びます。

5）表示された場合は「ショートカットを作成」を選びます。

6）名前を確認し、「追加」を押します。

7）ホーム画面のアイコンからアプリを起動します。

Androidの機種やChromeのバージョンによって、文言が「アプリをインストール」などに
変わる場合があります。その場合も画面の案内に従って追加してください。


============================================================
6. 初回起動後に行う確認
============================================================

1）画面下部の「追加」を押します。

2）「映画を観た」「食事をした」「場所へ行った」のいずれかを選びます。

3）試しに1件登録します。

4）「履歴」に登録内容が表示されることを確認します。

5）位置を登録した場合は、「地図」にピンが表示されることを確認します。

6）右上の歯車ボタンを押します。

7）「バックアップを保存」を押し、ファイルを保存できることを確認します。

現在地ボタンを使用すると、ブラウザから位置情報の利用許可を求められます。
使用する場合は、このGitHub Pagesサイトに対して位置情報を許可してください。


============================================================
7. 記録データについて特に重要なこと
============================================================

このアプリにはログインやクラウドデータベースがありません。
映画、旅行、食事、評価、感想、ポスター、写真は、使ったブラウザ内だけに保存されます。

そのため、次の場合は同じ記録が自動では表示されません。

・別のiPhoneやAndroidへ変更した
・SafariからChromeへ変更した
・パソコンで同じURLを開いた
・GitHubユーザー名やリポジトリ名を変更し、URLが変わった

また、次の操作でデータが消える場合があります。

・SafariやChromeのWebサイトデータを削除した
・ブラウザアプリを削除した
・ホーム画面のWebアプリを削除し、関連データも消去された
・端末のストレージ整理機能によってWebサイトデータが削除された

プライベートブラウズ／シークレットモードでの常用は避けてください。


============================================================
8. バックアップを保存する
============================================================

1）アプリ右上の歯車ボタンを押します。

2）「バックアップを保存」を押します。

3）保存先を選べる場合は、iPhoneならiCloud Drive、AndroidならGoogle Driveなどを選びます。

4）ファイル名は、例えば次のようになります。

reel-places-backup-20260910.reelplaces

5）保存されたことを「ファイル」アプリなどで確認します。

このファイルには、記録した文字情報、映画ポスター、食事写真も含まれます。
写真が増えるとバックアップファイルも大きくなります。

おすすめのバックアップ頻度：

・多く記録した日
・月に1回
・ブラウザや端末を更新する前
・ホーム画面のアイコンを削除する前
・GitHub PagesのURLを変更する前


============================================================
9. バックアップから復元する
============================================================

1）復元先のスマホでアプリを開きます。

2）右上の歯車ボタンを押します。

3）「バックアップから復元」を押します。

4）iCloud Drive、Google Drive、端末のダウンロードフォルダなどから、
   `.reelplaces` ファイルを選びます。

5）件数を確認し、復元を実行します。

注意：

復元すると、現在そのブラウザに入っているデータは、選んだバックアップの内容で
置き換えられます。必要な現在データがある場合は、復元前に別のバックアップを保存してください。


============================================================
10. アプリを更新したときの公開方法
============================================================

index.html、styles.css、app.jsなどを修正した後は、PowerShellで次を実行します。

cd "C:\Users\tanak\OneDrive - 株式会社　ウェルリサーチ　\ドキュメント\hobby\recording"
git add .
git commit -m "アプリを更新"
git push origin main

GitHub Pagesはmainブランチへの変更を検出し、自動的に公開ページを更新します。
反映には数分かかる場合があります。

公開ページを更新しても、URLと使用ブラウザが同じであれば、通常、記録は残ります。
ただし、更新前には念のためバックアップを保存してください。

iPhoneで古い画面が表示される場合：

・アプリをいったん閉じて開き直す
・Safariで公開URLを開き、ページを再読み込みする
・数分待ってから再度開く

11. うまくいかない場合
============================================================

【公開URLが404になる】

・GitHubリポジトリ直下に `index.html` があるか確認します。
・Settings → Pagesで、Branchが `main`、フォルダが `/(root)` か確認します。
・設定直後は、5～10分ほど待ってから再読み込みします。
・GitHubリポジトリの「Actions」を開き、Pagesの処理が完了しているか確認します。

【地図だけ表示されない】

・スマホがインターネットへ接続されているか確認します。
・通信を制限する機能やコンテンツブロッカーを一時的に無効にして確認します。
・地図はLeafletとOpenStreetMapをインターネットから読み込んでいます。

【現在地を取得できない】

・SafariまたはChromeに位置情報の使用を許可します。
・端末本体の位置情報サービスがオンになっているか確認します。
・取得できない場合でも、地図をタップして位置を指定できます。

【別のスマホで記録が表示されない】

正常な動作です。元のスマホでバックアップを保存し、新しいスマホで復元してください。

【ホーム画面に追加が見つからない】

iPhone：Safariで開いているか確認し、共有メニューの「アクションを編集」を確認します。
Android：Chromeの「︙」メニューから「ホーム画面に追加」を確認します。

【写真が多く、動作が重くなった】

・先にバックアップを保存します。
・不要な記録や写真を整理します。
・端末の空き容量を確認します。
