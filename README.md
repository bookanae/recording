# Reel & Places

観た映画と訪れた場所を、自分の端末に記録する個人用Webアプリです。iPhoneでの操作を優先しつつ、PCでも利用できます。

サーバー、ログイン、映画情報APIは使いません。データが外部サービスへ送信されることもありません（地図画像の表示には OpenStreetMap を利用します）。

## できること

- 映画の鑑賞日、公開年、鑑賞方法、5段階（0.1刻み）の評価、感想、タグを記録
- Prime、Netflix、Disney+、TVerなど、利用した配信サービスを記録
- 映画の監督、主演、ポスター画像を登録
- 同じ映画を映画館・配信などで何度でも記録
- 映画館、旅行先、その他の場所を地図へ登録
- お店、料理、評価、場所、写真を「食事」として記録
- 同じ場所への複数の訪問を、1つのピンにまとめて表示
- 映画タイトル、年、評価、鑑賞方法、映画館、タグで絞り込み
- 映画・訪問を日付順のタイムラインで表示
- 記録の追加、編集、削除
- バックアップファイルの保存と復元
- 端末のダークモードに合わせた表示

## ファイル構成

```text
recording/
├── index.html   # 画面の構造
├── styles.css   # スマホ優先のデザイン
├── app.js       # 保存、表示、検索、地図などの機能
└── README.md    # この説明書
```

依存ライブラリは地図表示用の [Leaflet](https://leafletjs.com/) だけです。Leaflet と OpenStreetMap の地図はCDNから読み込むため、地図表示にはインターネット接続が必要です。それ以外の記録の閲覧・編集は、読み込み済みのページ上で動作します。

## データ構造

ブラウザの IndexedDB に、次の3種類を分けて保存します。

- `movies`: 作品（タイトル）
- `places`: 場所（名前、映画館・旅行・食事などのカテゴリ、緯度・経度）
- `logs`: 鑑賞・食事・訪問の1回ごとの記録

「作品」と「1回の鑑賞」、「場所」と「1回の訪問」を分けているため、同じ作品を何度観ても、同じ映画館へ何度行っても重複せずにまとめられます。

## GitHub Pagesで公開する方法

1. このフォルダの内容をGitHubリポジトリへプッシュします。
2. GitHubのリポジトリ画面で **Settings** を開きます。
3. 左側の **Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にします。
5. Branch で公開するブランチ（通常は `main`）と **/(root)** を選び、**Save** を押します。
6. 数分後に表示されるURLをiPhoneのSafariで開きます。

iPhoneでは、Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アプリのようにすぐ開けます。

## データの保存場所

記録と選択した画像は、アプリを開いたブラウザの IndexedDB に保存されます。画像は端末内で見やすい大きさへ自動縮小されます。GitHubやOpenStreetMapへ記録内容や画像は送信されません。

次の場合は別の保存領域として扱われます。

- SafariとChromeなど、違うブラウザで開いた場合
- GitHub PagesのURLが変わった場合
- 別のiPhoneやPCで開いた場合

ブラウザの履歴・Webサイトデータを削除すると、記録も消える場合があります。定期的なバックアップをおすすめします。

## バックアップ方法

1. 画面右上の歯車ボタンを押します。
2. **バックアップを保存** を押します。
3. ダウンロードされた `.reelplaces` ファイルを、iCloud Driveなど安全な場所へ保存します。ポスターや食事写真もこのファイルに含まれます。

復元するときは、同じ設定画面で **バックアップから復元** を押し、保存したファイルを選ぶだけです。復元すると、現在のデータはバックアップ内のデータに置き換わります。

## ローカルで確認する方法

ファイルを直接ダブルクリックするより、簡単なローカルサーバーでの確認をおすすめします。Pythonが入っている場合は、このフォルダで次を実行します。

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 補足

- 地図で「現在地」を使う場合、ブラウザから位置情報の許可を求められます。
- 写真が多いほどバックアップファイルも大きくなります。定期的にバックアップし、端末の空き容量にもご注意ください。
- 公開ページを更新しても、同じURL・同じブラウザであれば通常は記録が残ります。
- 大きな変更やブラウザのデータ整理を行う前には、必ずバックアップを保存してください。
